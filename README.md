## Database Schema

Here’s an overview of the database structure:

### 1. **Products table**
- **product_id**: Unique identifier for each product (primary key).
- **product_name**: Name of the product.
- **category**: Category to which the product belongs.
- **subcategory**: Subcategory of the product.
- **unit_price**: price per unit of the product.

### 2. **stores Table**
- **store_id**: Unique identifier for each store (primary key_.
- **store_name**: Name of the store.
- **city**: City where the store is located.
- **country**: Country where the store is operates.

### 3. **Sales Table**
- **Order_id**: Unique identifier for each sales order (primary key).
- **order_date**: Date when the order was placed.
- **Product_id**: Foreign key referencing *products* table.
- **qty**: Quantity of the product sold.
- **discount_percentage**: Discount applied to the order.
- **unit_price**: Price per unit of the product at the time of sales.
- **store_id**: Foreign key referencing *stores* table.

### 4. **Inventory Table**
- **inventory_id**: Unique identifier for each inventory records (primary key).
- **product_id**: Foreign key referencing the *products* table.
- **current_stock**: Current stock level of the product.
- **reorder_level**: Maximun stock level to trigger a reorder.

## Getting Started

### Creating Tables

```sql
CREATE TABLE products
(
	product_id VARCHAR(10) PRIMARY KEY,	
	product_name VARCHAR(35) ,
	category	VARCHAR(20),
	subcategory	VARCHAR(20),
	unit_pice FLOAT
);
```

```sql
CREATE TABLE stores
(
	store_id	VARCHAR(10) PRIMARY KEY,
	store_name	VARCHAR(25),
	city	VARCHAR(25),
	country VARCHAR(25)
);
```

```sql
CREATE TABLE sales
(
	order_id 	VARCHAR(10) PRIMARY KEY,
	order_date	DATE,
	product_id	VARCHAR(10) REFERENCES products(product_id), --FK
	qty	INT,
	discount_percentage	FLOAT,
	unit_price FLOAT,	
	store_id VARCHAR(10) REFERENCES stores(store_id) --FK
);
```

```sql
CREATE TABLE inventory
(
	inventory_id SERIAL PRIMARY KEY,
	product_id	VARCHAR(10) REFERENCES products(product_id), --FK
	current_stock 	INT,
	reorder_level INT
);
```

## Q&A
### 1. Find the average discount and tatol revenue generated for each sub-category across all stores
```sql
select 
	p.subcategory,
	round(avg(s.discount_percentage::numeric),2) as avg_discount,
	round(sum(s.net_sales::numeric),2) as total_sales
from products as p
join
sales as s
on p.product_id = s.product_id
group by 1
```
### 2. Retrieve the top three products by total sales revenue in each store.
```sql
select
	*
from
(
select 
	p.product_name,
	st.store_name,
	sum(s.net_sales) as total_sales,
	row_number()over(partition by st.store_name order by sum(s.net_sales) desc) as rank_num
from products as p
join 
sales as s
on p.product_id = s.product_id
join
stores as st
on s.store_id = st.store_id
group by 1,2
) as t1
where rank_num <=3
```
### 3. Determine the product with the highest number of units sold in each category and store.
```sql
select * from
(
select 
	p.product_name,
	p.category,
	st.store_name,
	sum(s.qty) as total_unit_sold,
	row_number()over(partition by p.category, st.store_name order by sum(s.qty)) as rn
from products as p
join
sales as s
on p.product_id = s.product_id
join
stores as st
on s.store_id = st.store_id
group by 1,2,3
) as ranked_product
where rn = 1
```
### 4. Find the average sales revenue generated by each product in stores where it sold above the average sales quantity.
```sql
select * from
(
select 
	p.product_name,
	st.store_name,
	avg(s.net_sales) as avg_sales_rev,
	avg(s.qty) as avg_sales_qty
from products as p
join
sales as s
on p.product_id = s.product_id
join stores as st
on s.store_id = st.store_id
group by 1,2
) t1
where avg_sales_rev > avg_sales_qty
```

### 6. Use window function to identify the latest sales for each product in each store.
```sql
select * from
(
	select 
	p.product_name,
	st.store_name,
	s.order_date,
	s.net_sales,

from products as p
join sales as s
on p.product_id = s.product_id
join stores as st
on s.store_id = s.store_id
```

### 7. Determine the average re-order level for products across different sub-category.
```sql
select
	p.subcategory,
	avg(i.reorder_level) as avg_reorder_level
from products as p
join
inventory as i
on p.product_id = i.product_id
group by 1
order by avg_reorder_level desc
```
### 8. Retrieve stores with a total discount percentage above the average discount for all stores.
```sql
select 
	st.store_id,
	st.store_name,
	sum(discount_percentage) as total_discount_percentage
from sales as s

stores as st
on s.store_id = st.store_id
group by 1,2
having sum(discount_percentage) >
								(select avg(total_discount)from sales)
```

### 9. Find the total quantity sold for each product category across all stores.

### 10. List each store's total sales revenue, including both discounted and non-discounted prices.
```sql
select
	st.store_id,
	st.store_name,
	sum(s.qty * s.unit_price) as gross_rev,
	sum(s.qty * s.unit_price * (1- s.discount_percentage / 100)) as net_rev
from sales as s
join
stores as st
on s.store_id = st.store_id
group by 1,2
```

### 13. Find the number of unique products sold in each store within 'Furniture' category.
```sql
select
	st.store_id,
	st.store_name,
	count(distinct p.product_id) as unique_product_sold
from products as p
join
sales as s
on p.product_id = s.product_id
join
stores as st
on s.store_id = st.store_id
where p.category = 'Furniture'
group by 1,2
order by unique_product_sold desc
```
### 14. Categorize stores based on sales performance as "High," "Medium," or "Low" using the total sales revenue.
```sql
select 
	st.store_id,
	st.store_name,
	sum(net_sales) as total_sales_revenue,
	case
		when sum(net_sales) >= 50000 then 'High'
		when sum(net_sales) between 20000 and 49999 then 'Medium'
		else 'Low'
	end as sales_performance
from sales as s
join
stores as st
on s.store_id = st.store_id
group by 1,2
order by 3 desc
```
### 15. Create a column indicating if the product price is above or below the average price for its category.
```sql
select
	p.product_id,
	p.product_name,
	p.category,
	p.unit_pice,
	avg(p.unit_pice)over(partition by p.category) as avg_category_price,
	case
		when p.unit_pice > avg(p.unit_pice)over(partition by p.category) then 'Above avg'
		when p.unit_pice < avg(p.unit_pice)over(partition by p.category) then 'below avg'
		else 'avg price'
	end as price_status
from products as p
```
### 16. Display the reorder status for each product in inventory as "Low Stock" if current stock is below the reorder level, otherwise "Sufficient Stock."
```sql
select 
	i.inventory_id,
	p.product_id,
	p.product_name,
	i.current_stock,
	i.reorder_level,
	case
		when i.current_stock < i.reorder_level then 'Low Stock'
		else 'Sufficient Stock'
	end as reorder_status
from products as p
join
inventory as i
on p.product_id = i.product_id
```
### 17. Identify each store’s top-selling product and categorize it as “Top Performer” or “Underperformer” based on a specified sales quantity threshold.
```sql
with product_sales as 
(
select 
	st.store_id,
	st.store_name,
	p.product_id,
	p.product_name,
	sum(s.qty) as total_qty_sold,
	rank()over(partition by st.store_id order by sum(s.qty) desc) as ranking
from products as p
join
sales as s
on s.product_id = p.product_id
join
stores as st
on s.store_id = st.store_id
group by 1,2,3,4
)
select
	store_id,
	store_name,
	product_id,
	product_name,
	total_qty_sold,
	case
		when total_qty_sold >=100 then 'Top performer'
		else 'Under performer'
	end as performance_status
from product_sales
where ranking = 1
order by total_qty_sold desc
```
### 18. For each product, indicate if it has a "High Discount," "Moderate Discount," or "Low Discount" based on the discount percentage.
```sql
select 
	p.product_id,
	p.product_name,
	s.discount_percentage,
	case
		when s.discount_percentage >=30 then 'high discount'
		when s.discount_percentage between 10 and 29 then 'moderate discount'
		else 'low discont'
	end as discount_category
from products as p
join
sales as s
on s.product_id = p.product_id
```
### 19. Mark stores as "Overstocked" or "Understocked" if current stock is above or below reorder level.
```sql
select 
	p.product_id,
	p.product_name,
	i.current_stock,
	i.reorder_level,
	case
		when i.current_stock > i.reorder_level then 'over stocked'
		when i.current_stock < i.reorder_level then 'under stocked'
		else 'balanced stocked'
	end as stock_status
from inventory as i
join
products as p
on i.product_id = p.product_id
```
### 20. List the top five products by sales quantity within each store.
```sql
-- 1.
with top_products
as
(
select 
	st.store_id,

	p.product_id,
```
